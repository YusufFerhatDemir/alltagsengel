# § 45a SGB XI — Anerkennung als Anbieter nach Bundesland

> **Überblick für die Expansion von Alltagsengel UG**  
> Stand: Juli 2026

Die Anerkennung nach § 45a SGB XI ist **Ländersache**. Jedes Bundesland hat eine eigene Verordnung mit teils erheblich unterschiedlichen Anforderungen. Eine Anerkennung gilt **nur im jeweiligen Bundesland** (bzw. für die beantragte Region).

---

## Hessen ✅ (aktueller Antrag)

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Pflegeunterstützungsverordnung (PfluV) |
| **Zuständige Behörde** | Magistrat (kreisfreie Städte) / Kreisausschuss (Landkreise) |
| **Antragsform** | Schriftlich oder elektronisch, Erhebungsbogen (PDF) |
| **Gewerbliche Anbieter** | Anbieterform II — Entlastung von Pflegenden + Entlastung im Alltag (keine Betreuung!) |
| **Fachkraft nötig** | Ab >3 leistungserbringenden Personen (bei Entlastung von Pflegenden) |
| **Basisschulung** | Mind. 30 Stunden |
| **Max. Preis** | 30 €/Std. (Nr. 2) / 25 €/Std. (Nr. 3) |
| **Gebühren** | Keine Antragsgebühr erwähnt |
| **Besonderheiten** | Pro Angebot ein Erhebungsbogen; IK-Nummer erforderlich |

---

## Bayern

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Alltagsbegleitungsverordnung (AllBV) / AVPflegeVG |
| **Zuständige Behörde** | Bayerisches Landesamt für Pflege (LfP), Amberg — zentral für ganz Bayern |
| **Antragsform** | Antragsformular des LfP (PDF), postalisch oder elektronisch |
| **Gewerbliche Anbieter** | Zulässig als selbstständig tätige Einzelpersonen oder gewerbliche Träger |
| **Fachkraft nötig** | Ja, leitende Fachkraft mit pflegerischer oder sozialpädagogischer Qualifikation |
| **Basisschulung** | Mindestens 40 Stunden (strenger als Hessen!) |
| **Max. Preis** | Landesrechtlich geregelt, variiert |
| **Gebühren** | Keine Antragsgebühr |
| **Bearbeitungszeit** | Ca. 4–8 Wochen |
| **Besonderheiten** | Zentrale Zuständigkeit (LfP statt Kommunen); seit 2024 auch Registrierung für einfache Angebote möglich |

---

## Nordrhein-Westfalen (NRW)

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Anerkennungs- und Förderungsverordnung (AnFöVO) |
| **Zuständige Behörde** | Kreise und kreisfreie Städte (dezentral) |
| **Antragsform** | **Elektronisch über Portal „PfAD.uia"** — kein Papierformular! |
| **Gewerbliche Anbieter** | Zulässig als „sonstige gewerbliche Anbieter ohne Versorgungsvertrag" |
| **Fachkraft nötig** | Ja, Fachkraft für Leitung und Anleitung |
| **Basisschulung** | Pflegekurs nach § 45 SGB XI reicht als Mindestqualifikation |
| **Max. Preis** | Keine landesweite Preisobergrenze in der AnFöVO |
| **Gebühren** | **Gebührenpflichtig!** (Höhe variiert nach Kommune) |
| **Besonderheiten** | Digitales Antragsportal; vergleichsweise niedrige Hürde bei Schulung; NRW ist einer der größten Märkte |

---

## Baden-Württemberg

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Unterstützungsangebote-Verordnung (UstA-VO) |
| **Zuständige Behörde** | Stadt- und Landkreise (dezentral) |
| **Antragsform** | Schriftlich, Formular der jeweiligen Kommune |
| **Gewerbliche Anbieter** | Zulässig; auch Einzelpersonen können sich anerkennen lassen |
| **Fachkraft nötig** | Ja, eine Fachkraft nach § 6 UstA-VO |
| **Basisschulung** | Mind. 30–40 Stunden |
| **Besonderheiten** | Fach- und Koordinierungsstelle bei der Alzheimer Gesellschaft BW berät Anbieter; relativ gut dokumentiertes Verfahren |

---

## Berlin

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Pflegeunterstützungsverordnung Berlin (PfluVBln) |
| **Zuständige Behörde** | Senatsverwaltung für Gesundheit, Pflege und Gleichstellung |
| **Antragsform** | Schriftlich an die Senatsverwaltung |
| **Gewerbliche Anbieter** | **Einschränkung:** Es muss eine juristische Person vorliegen (GmbH, UG, e.V.) — Einzelpersonen/Einzelunternehmen sind NICHT zulässig! |
| **Fachkraft nötig** | Ja, Fachkraft mit min. 3-jähriger Ausbildung |
| **Mindestanzahl Helfer** | Mind. 3 ehrenamtliche oder hauptamtliche Helfer |
| **Besonderheiten** | Strengere Anforderungen als andere Bundesländer; Alltagsengel als UG erfüllt die Rechtsform-Voraussetzung |

---

## Niedersachsen

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Niedersächsische Verordnung über Angebote zur Unterstützung im Alltag (NdsAUAVO) |
| **Zuständige Behörde** | Nds. Landesamt für Soziales, Jugend und Familie |
| **Antragsform** | Formulare auf der Website des Landesamts |
| **Gewerbliche Anbieter** | Zulässig |
| **Besonderheiten** | Zentrale Zuständigkeit beim Landesamt (ähnlich Bayern) |

---

## Hamburg

| Aspekt | Details |
|--------|---------|
| **Rechtsgrundlage** | Hamburgische Pflegeengagementverordnung (HmbPflegeEngVO) |
| **Zuständige Behörde** | Behörde für Gesundheit und Verbraucherschutz (BGV) |
| **Gewerbliche Anbieter** | Zulässig |
| **Besonderheiten** | Stadtstaaten-Regelung — nur eine Behörde zuständig |

## Zusammenfassung — Expansions-Prioritäten

| Bundesland | Marktgröße | Komplexität | Empfehlung |
|-----------|-----------|-------------|------------|
| **Hessen** | Mittel | Mittel | ✅ Läuft — Erstantrag |
| **NRW** | Sehr groß | Niedrig–Mittel | ⭐ Hohe Priorität — größter Markt, digitales Portal |
| **Bayern** | Groß | Mittel | ⭐ Hohe Priorität — zentrale Behörde, 4-8 Wochen |
| **Baden-Württemberg** | Groß | Mittel | Gut machbar |
| **Berlin** | Mittel | Hoch | UG erfüllt Rechtsform — aber strenger |
| **Niedersachsen** | Mittel | Mittel | Zentrale Behörde, überschaubar |
| **Hamburg** | Klein | Niedrig | Einfach, aber kleiner Markt |
