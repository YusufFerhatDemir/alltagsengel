## 3. Schritt 2 — Screening und Pruefung

### 3.1 Screening-Checkliste

**Grundvoraussetzungen (Muss-Kriterien):**

- [ ] Mindestalter 18 Jahre
- [ ] Wohnsitz in einer abgedeckten Region (Rhein-Main)
- [ ] Arbeitserlaubnis in Deutschland
- [ ] Keine einschlaegigen Eintraege im Fuehrungszeugnis
- [ ] Bereitschaft zur §45a-Schulung (falls nicht vorhanden)
- [ ] Sprachkenntnisse Deutsch (mind. B2)

**Qualifikation (Soll-Kriterien, gewichtet):**

| Kriterium | Punkte | Hinweis |
|-----------|--------|---------|
| §45a-Schulung bereits absolviert | 3 | Zertifikat pruefen |
| Erfahrung in Pflege / Betreuung / Sozialarbeit | 2 | Lebenslauf pruefen |
| Ausbildung im Gesundheits- / Sozialwesen | 2 | Nachweise pruefen |
| Fuehrerschein + eigenes Fahrzeug | 1 | Fuer Mobiliaet bei Einsaetzen |
| Erste-Hilfe-Kurs (nicht aelter als 2 Jahre) | 1 | Nachweis pruefen |
| Zusaetzliche Sprachkenntnisse | 1 | Tuerkisch, Russisch, Arabisch etc. besonders wertvoll |

**Bewertung:**
- 7+ Punkte: Sofort einladen
- 4–6 Punkte: Einladen, Schulungsbedarf pruefen
- 0–3 Punkte: Absage oder Rueckstellung bis Schulung moeglich

### 3.2 Erforderliche Dokumente

| Dokument | Zeitpunkt | Pflicht |
|----------|-----------|---------|
| Lebenslauf | Bei Bewerbung | Ja |
| Erweitertes Fuehrungszeugnis (Belegart OE) | Vor Vertragsschluss | Ja |
| §45a-Schulungszertifikat | Vor erstem Einsatz | Ja (sonst Schulung durch Alltagsengel) |
| Erste-Hilfe-Nachweis | Vor erstem Einsatz | Ja |
| Personalausweis / Reisepass (Kopie) | Vor Vertragsschluss | Ja |
| Arbeitserlaubnis (bei Nicht-EU-Buergern) | Vor Vertragsschluss | Ja |
| Sozialversicherungsausweis | Vor Vertragsschluss | Ja |
| Steuer-ID | Vor Vertragsschluss | Ja |
| Bankverbindung (IBAN) | Vor Vertragsschluss | Ja |
| Referenzen (mind. 1) | Vor Vertragsschluss | Empfohlen |
| Gesundheitszeugnis | Bei Bedarf | Optional |

### 3.3 Fuehrungszeugnis

- **Typ:** Erweitertes Fuehrungszeugnis (Belegart OE) — zeigt auch Sexualstraftaten
- **Beantragung:** Bewerber beantragt beim Buergeramt, Alltagsengel stellt Aufforderungsschreiben
- **Kosten:** Traegt Alltagsengel (Erstattung gegen Vorlage der Quittung)
- **Gueltigkeit:** Nicht aelter als 3 Monate bei Vorlage
- **Erneuerung:** Alle 2 Jahre

### 3.4 Referenzpruefung

- Mindestens 1 Referenz einholen (ehemaliger Arbeitgeber oder Ausbildungsstaette)
- Telefonisch oder per E-Mail
- Fragen: Zuverlaessigkeit, Umgang mit Menschen, Empathie, Konfliktsituationen
- Dokumentation der Referenz im Bewerberprofil

## 4. Schritt 3 — Vorstellungsgespraech

### 4.1 Rahmenbedingungen

| Aspekt | Detail |
|--------|--------|
| Dauer | 45–60 Minuten |
| Format | Persoenlich (bevorzugt) oder Video-Call |
| Teilnehmer | 1 Interviewer von Alltagsengel + Bewerber |
| Vorbereitung | Bewerbungsunterlagen sichten, Screening-Ergebnis einsehen |

### 4.2 Gespraechsleitfaden

**Block 1 — Begruessen und Aufwaermen (5 Min.)**

- Willkommen heissen, Getraenk anbieten
- Ablauf des Gespraechs erklaeren
- Alltagsengel kurz vorstellen (Mission, Werte, Arbeitsmodell)

**Block 2 — Person kennenlernen (15 Min.)**

- „Erzaehlen Sie uns etwas ueber sich — was treibt Sie an?"
- „Warum moechten Sie als Alltagsbegleiter arbeiten?"
- „Haben Sie Erfahrung mit aelteren Menschen oder Menschen mit Einschraenkungen?"
- „Wie wuerden Freunde oder Familie Sie beschreiben?"

**Block 3 — Situative Fragen (15 Min.)**

- „Eine Kundin moechte unbedingt alleine einkaufen gehen, Sie sehen aber, dass sie
  unsicher auf den Beinen ist. Wie reagieren Sie?"
- „Ein Kunde ist heute sehr schweigsam und niedergeschlagen. Was tun Sie?"
- „Sie kommen zum Einsatz und der Kunde oeffnet nicht die Tuer. Wie gehen Sie vor?"
- „Die Angehoerige ruft an und beschwert sich, dass Sie zu wenig machen.
  Wie reagieren Sie?"

**Block 4 — Praktisches (10 Min.)**

- Verfuegbarkeit klaeren (Wochentage, Uhrzeiten, Stunden pro Woche)
- Mobilitaet besprechen (Anfahrt, Radius)
- §45a-Schulung besprechen (vorhanden oder Schulungstermin planen)
- Verguetunsmodell erklaeren
- Erwartungen an Dokumentation und Berichtswesen

**Block 5 — Fragen und Abschluss (10 Min.)**

- Bewerber: „Haben Sie Fragen an uns?"
- Naechste Schritte erklaeren (Zeitrahmen fuer Entscheidung, fehlende Unterlagen)
- Verabschiedung

### 4.3 Bewertungsbogen (intern)

| Kriterium | 1 (schwach) | 2 | 3 | 4 | 5 (stark) |
|-----------|-------------|---|---|---|-----------|
| Empathie und Warmherzigkeit | | | | | |
| Zuverlaessigkeit (Eindruck) | | | | | |
| Kommunikationsfaehigkeit | | | | | |
| Problemloesungskompetenz | | | | | |
| Motivation und Engagement | | | | | |
| Fachliche Eignung | | | | | |
| Gesamteindruck | | | | | |

**Entscheidung:**
- Durchschnitt 4+: Zusage
- Durchschnitt 3–3,9: Zusage mit Auflagen (z. B. zusaetzliche Schulung)
- Durchschnitt unter 3: Absage

## 6. Schritt 5 — Einarbeitungsplan

### 6.1 Woche 1 — Theorie und Grundlagen

| Tag | Inhalt | Dauer |
|-----|--------|-------|
| Tag 1 | Willkommen, Unternehmenswerte, Leitbild, Organisation | 3 Std. |
| Tag 1 | IT-Einfuehrung: App, Dokumentation, Dienstplan | 2 Std. |
| Tag 2 | §45a-Schulung (falls nicht vorhanden) oder Auffrischung | 8 Std. |
| Tag 3 | Erste Hilfe (falls nicht aktuell) | 8 Std. |
| Tag 4 | Kommunikation mit Kunden und Angehoerigen | 3 Std. |
| Tag 4 | Umgang mit Notfaellen und schwierigen Situationen | 2 Std. |
| Tag 5 | Dokumentation und Berichtswesen, Datenschutz | 3 Std. |
| Tag 5 | Abrechnung und organisatorische Ablaeufe | 2 Std. |

### 6.2 Woche 2 — Praxis und Hospitation

| Tag | Inhalt | Dauer |
|-----|--------|-------|
| Tag 6–7 | Hospitation bei erfahrenem Begleiter (2 verschiedene Kunden) | 2x 4 Std. |
| Tag 8 | Reflexionsgespraech: Eindruecke, Fragen, Unsicherheiten | 2 Std. |
| Tag 9 | Begleiteter Ersteinsatz mit Mentor (eigener Kunde) | 4 Std. |
| Tag 10 | Nachbesprechung + Freigabe fuer selbststaendige Einsaetze | 2 Std. |

### 6.3 Einarbeitungs-Checkliste (Unterschrift Begleiter + Mentor)

- [ ] Unternehmenswerte und Leitbild vermittelt
- [ ] App-Zugang eingerichtet und getestet
- [ ] Dokumentationsvorlagen erklaert und geubt
- [ ] §45a-Schulung absolviert oder nachgewiesen
- [ ] Erste-Hilfe-Kurs absolviert oder nachgewiesen
- [ ] Hospitation durchgefuehrt (mind. 2 Einsaetze)
- [ ] Begleiteter Ersteinsatz absolviert
- [ ] Notfallprotokoll bekannt
- [ ] Datenschutzrichtlinien verstanden
- [ ] Schweigepflicht verstanden
- [ ] Dienstplan-System verstanden
- [ ] Ansprechpartner bei Fragen bekannt

## 7. Laufende Betreuung und Qualitaetssicherung

### 7.1 Probezeit (3 Monate)

| Zeitpunkt | Massnahme |
|-----------|-----------|
| Nach 2 Wochen | Check-in-Gespraech: Wie laeuft es? Fragen? Probleme? |
| Nach 6 Wochen | Halbzeit-Feedback: Kundenfeedback einholen, Staerken / Entwicklungsfelder |
| Nach 12 Wochen | Probezeitgespraech: Uebernahme oder Beendigung |

### 7.2 Fortlaufend

- Monatlicher Kurz-Check-in (telefonisch oder persoenlich)
- Quartalsweise Weiterbildung / Supervision
- Jaehrliche Auffrischung §45a-Inhalte
- Regelmaessige Kundenfeedback-Auswertung
- Erweitertes Fuehrungszeugnis alle 2 Jahre erneuern
